02 / Quick start

Set up from your terminal.

The portable ZIP includes Node.js and its dependencies. Choose Premiere Pro and Photoshop below, or use --apps all.

  1. Download and verify

    Get your platform ZIP from GitHub Releases, compare its SHA-256 hash with SHA256SUMS, then extract it.

  2. Choose your applications

    Run the command for your system from the extracted folder. On Windows or macOS, restart Adobe and open the suite's CEP panel.

  3. Connect your MCP client

    Import the generated mcp-servers.json. Use adobe-mcp doctor --live while the servers run to check their connections.

Full installation guide ↗

Check CEP compatibility first. On Windows and macOS, --enable-unsigned enables unsigned development panels for your user account. Native workflows have not yet been verified inside Adobe applications. This project uses CEP/ExtendScript and does not include a UXP adapter.

03 / Behind the tools

Local by design.

An MCP client launches each selected server over stdio. The server talks to its Adobe panel over an authenticated loopback connection. Every server also provides discovery resources and prompts that work with the panel disconnected.

Read the architecture notes ↗

Updates on your terms

The manager checks for stable releases and prints a notice when one is available. Run adobe-mcp update when ready, or use adobe-mcp rollback to return to the previous installed version.
