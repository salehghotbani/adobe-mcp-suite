# Project branding

- `adobe-mcp-icon.png`: active blue pen icon used in the README and generated CEP panels.
- `blue-pen-prompt.txt`: original generation and edit instructions for the active icon.
- `applications.svg`: named letter badges displayed beside the blue pen icon: Pr (Premiere Pro), Ps (Photoshop), Me (Media Encoder), Ai (Illustrator), Id (InDesign), Ae (After Effects), and Au (Audition). These are independently drawn identification badges, not official logo files. They indicate applications rather than certified version compatibility.
- `archive/red-icon.png`: the earlier red design, preserved for reference.
- `archive/red-icon-prompt.txt`: generation instructions for the earlier design.

Run `npm run setup` after replacing the active icon to refresh generated panels. Branding assets do not imply Adobe endorsement or grant rights to Adobe trademarks.
